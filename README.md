# TechToolBox

Practical tools for software testers, by Santhosh Tuppad.

| Tool | What it does |
|------|--------------|
| [**Review Red Flags**](Google%20Review%20Pleasant%20and%20Unpleasant%20Extension/) | Chrome extension that finds unpleasant reviews and red flags in any app's Google Play reviews: crashes, login, payments, updates and more. Loads every review and exports an HTML dashboard. |
| [**Sankalpa**](Sankalpa/) | Form testing inside Chrome DevTools. Finds every form on a site, works out each field's rules, and tests the browser **and** the server: focus, length limits, emoji, and what the server really accepts. Explains every failure, with evidence. |

Everything here runs on your own machine. See each tool's folder for a quick start.
